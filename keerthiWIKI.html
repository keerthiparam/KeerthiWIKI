Systems & Technical Documentation

YapFormer

Last Updated: Dec 2025 | Category: AI Architecture | Status: Completed | Documentation
Figure 2: Terminal-based UI architecture.

YapFormer is a sophisticated transformer model engineered entirely from scratch, bypassing standard high-level libraries. Co-developed with Shri Sai Aravind R, it secured 1st Place as the "Build From Scratch Champion" at the RootSprout hackathon.

▼ Model Architecture & Constraints

Designed to operate under strict compute limitations, the model utilizes a custom multi-head attention mechanism. It was trained exclusively on the TinyStories dataset to demonstrate that high-quality semantic generation is possible without massive parameter counts.

▼ Interface & Optimization

The frontend is a custom terminal-based UI developed independently by Keerthi, utilizing ASCII art rendering to visualize token generation in real-time. Optimization required managing memory leaks during the self-attention tensor calculations.

PhishMate

Last Updated: Jun 2025 | Category: NLP Security | Status: Active | Repository

PhishMate is a local-analysis Chrome extension identifying malicious web infrastructure within email clients. Selected by Major League Hacking (MLH) for their global broadcast, it won the Security & Online Safety Track at AmpliCode.

The core engine relies on a local BERT sequential model. Utilizing Natural Language Processing, it parses semantic context and grammatical anomalies in the DOM. By keeping NLP execution strictly local, the system ensures zero user-data transmission. Links are cross-referenced via API against the AbuseIPDB registry.

TimeCapsule

Last Updated: Jan 2026 | Category: Decentralized Systems | Status: Proof of Concept
Figure 3: IPFS Data Flow Diagram.

Engineered to circumvent internet censorship, TimeCapsule provides tamper-proof forensic web archiving.

▼ Data Flow & Component Architecture
  • Ingestion: Puppeteer executes a "forensic snapshot" of the target DOM, neutralizing external iframes.
  • Hashing: Content is hashed via SHA-256.
  • Storage: Uploaded to IPFS via @storacha/cli to generate a Content Identifier (CID).
  • Ledgering: OpenTimestamps anchors the hash to the Bitcoin blockchain.
  • Database: Metadata managed via Prisma ORM on PostgreSQL.
